# Web Builder 计划

## 项目概况
- **项目名称**：成品仓定点定位看板
- **一句话描述**：把 Excel 成品仓定点定位看板还原为网页版，按区域/货架/储位查看每个储位存放的商品（编码+规格型号），支持按编码或型号搜索定位到具体储位。
- **项目原型**：spa（单页应用，纯前端静态数据）
- **当前阶段**：Phase 0 - 需求采集

---

- [x] 项目目标和目标用户：仓库管理人员查看库存储位
- [x] 核心功能 / 页面列表：区域总览、储位布局展示、按编码/型号搜索定位

## 技术方案 (Phase 1)

| 层级 | 选型 | 理由 |
|------|------|------|
| 前端框架 | React 18 + Vite | 轻量、构建快 |
| UI/样式 | Tailwind CSS | 快速搭建看板 UI |
| 后端 | 无 | 静态数据 |
| 数据库 | 无 | 数据由 Python 解析 Excel 生成 JSON，内嵌前端 |

### 本地启动方式
```bash
npm install
npm run dev
```

### 目录结构
```
inventory-kanban/
├── public/
├── src/
│   ├── components/       # 区域卡片、货架卡片、储位卡片、搜索框
│   ├── data/kanban.json  # 从 Excel 解析的静态数据
│   ├── App.tsx
│   ├── main.tsx
│   └── index.css
├── index.html
├── package.json
├── vite.config.ts
└── tailwind.config.js
```

## 设计规格 (Phase 2)

- 工业仓储风：深蓝主色 + 琥珀黄强调，仓储标签质感
- 字体：中文黑体系统栈 + 等宽字体展示编码
- 布局：顶部搜索栏 + 区域筛选 + 货架/储位网格卡片

### 页面区块
#### 看板主页 `/`
- [x] 顶部：标题 + 搜索框（按编码/型号实时过滤）
- [x] 区域筛选条：10 个仓库区域 Tab
- [x] 储位网格：每个区域展示货架卡片，货架内按储位（左/右/层）分区，列出商品编码+型号
